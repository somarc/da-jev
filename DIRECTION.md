# Jev Field Lab — continuous trace

## Direction lock

Selected by the operator: **A — Continuous trace**, 2026-09-17.

**Thesis:** A small semantic judgment becomes useful when its entire path—from
intent to a verified observation—is visible and inspectable.

**System:** spatial publishing / catalog-as-navigation; a site-specific house
system, not a cinematic, Dualform, or painterly-paper implementation.

**Custom object:** one continuous execution trace. It becomes the homepage
ribbon, the operating-model rail, and the sequence inside each experiment.

**Law:** every result leads back to its input, judgment, deterministic boundary,
and evidence. Native scrolling follows the trace; motion never hides it.

**Field:** flat saffron (`#ffc72c`), near-black ink, and neutral reading surfaces.
Display type is Archivo Black; reading type is Instrument Sans; code uses
Roboto Mono. Fonts are self-hosted. No gradient, glass dashboard, stock AI brain,
particle tunnel, fake terminal, preloader, or scroll-jacking.

**Depth:** house. The first paint is real typography and authored structure,
not WebGL or a video dependency. The code-drawn direction plate is an original
visual study; it contains no measured data.

## Forbidden sibling

## Product and evidence contract

- The homepage communicates the division of labor; inner pages expose the proof.
- Astra owns open-ended planning and synthesis. Jev supplies bounded judgments.
- Deterministic code owns parsing, target/path binding, validation, authorization,
  command invocation, calculations, and verification. da-cli owns DA/EDS operations.
- A model answer, confidence score, descriptor, or `next[]` never grants authority.
- Public interactions replay recorded results. API credentials stay in the
  private Vault-backed experiment workflow, never in browser code.
- Label illustrative pilots, synthetic checks, and verified executions separately.
- Report API upstream time separately from CLI wall time and unmeasured agent
  orchestration. Do not manufacture an end-to-end total or a frontier speedup.
- Run DA operations with explicit `--qmd`. CLI process timings include journaling;
  primary outcomes and receipt outcomes remain separate. Never replay a completed
  operation just to repair or manufacture a receipt.
- Scope correctness to the frozen cases and labels. A small pilot is not general
  accuracy, calibration, or a production benchmark.
- Use this site to expose reproducible CLI friction. File focused, deduplicated
  upstream issues; do not silently make a second handwritten CLI manual here.

## Ownership and cascade

This greenfield site adopts a complete layer order:
`reset, tokens, base, layout, components, utilities`.

- Global: box model, inherited type, semantic colors, shared control primitives.
- Section: outer padding, content width, inter-region gaps, authored surface styles.
- Prose: relationships between headings, paragraphs, lists, and quotations.
- Block: internal layout, local rhythm, controls, and data presentation.
- Template: direct article regions only; no reach into nested blocks.

The migration includes the existing cards, columns, hero, header, footer,
fragment, and widget styles. Font-face registration is not a competing selector
layer. Blocks inherit the house; they do not invent parallel palettes.

## Acceptance criteria

- At least three substantial page archetypes: homepage, experiment, and long-form
  explanation, with a navigable multi-page evidence library.
- Real content and public experiment records live in DA, not Git fixtures.
- Each reported figure has a source, unit, scope, sample count, and limitation.
- Data failures preserve the authored source link and display an honest error;
  missing values never become zero-valued measurements.
- Keyboard-operable navigation, native pickers/disclosures, visible focus,
  one main H1, labeled controls, and textual outcome states.
- No page-level overflow at narrow mobile, tablet, compact, and wide desktop
  widths; test the exact boundaries introduced by the implementation.
- Sparse, missing, extra-cell, long-copy, and repeated-block states remain usable.
- No runtime dependencies, vendored `scripts/aem.js` edits, or cross-block imports
  other than the existing fragment helper.
- Lint, focused controller tests, actual browser checks, codebus verification,
  source-to-preview checks, and live delivery proof precede completion.
